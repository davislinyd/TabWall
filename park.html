說明

快捷鍵

  • Alt+S — 儲存目前分頁（截圖）
  • Alt+Shift+G — 儲存目前 Tab Group
  • Alt+O — 開關 TabWall 照片牆
  • / — 聚焦搜尋
  • ⌥+⌘+S — 開啟／關閉設定（⌥⌘S）
  • .* — 切換正規表示式搜尋（支援 /pattern/flags）
  • t/tag、n/note、re/regex + Tab — 進入 tag／note／regex 模式；all + Tab 回全搜
  • Esc — 關閉浮層／照片牆
  • ← → — 快照上一張／下一張

基本使用

點縮圖還原、標題複製連結；✎ note／tags；⤢ 快照；× 刪除。拖曳可重排；拖到另一張卡片中央可組成 Stack（還原為 Tab Group）。

Tab Group / Stack

Alt+Shift+G 存整組；拖曳 tab 疊合亦可建 Stack。▦ 成員面板可預覽、編輯、還原單一或整個 group。

複選

點「選擇」進入複選，勾選多張卡片後可批次還原、合併 tags、或刪除。

備份

精簡 JSON 不含截圖；完整 ZIP 含圖片。還原（覆蓋）取代全部；匯入（附加）只新增。可手動貼 URL 建卡；#GROUP:名稱 包住多行可建群組。

限制

chrome:// 等特殊頁無法截圖或注入。TabWall 的存檔不是 Chrome 書籤列內建的 Save group。

去重複

存分頁時若 URL 已存在會詢問你如何處置。工具列「掃描重複」可掃描整牆並人工保留／刪除。

偵測到重複 URL

牆內已有相同完整 URL 的分頁。請選擇如何處置。
