說明

快捷鍵

  • 以上四項快捷鍵由瀏覽器管理，請在 Chrome／Edge 快捷鍵設定頁設定。
  • / — 聚焦搜尋
  • ⌥+/ — 在任何分頁搜尋已存項目（不必開啟 TabWall）
  • ⌥+A — 在一般分頁開啟 AI 面板
  • ⌥+⌘+S — 開啟／關閉設定（⌥⌘S）
  • .* — 切換正規表示式搜尋（支援 /pattern/flags）
  • t/tag、n/note、g/group、re/regex + Tab — 進入 tag／note／group／regex 模式；all + Tab 回全搜
  • Esc — 關閉浮層／空間畫布
  • ⌘+Z — 復原上一動作（誤 Stack 或連線）
  • ⌘+⇧+Z — 重做 Stack／連線
  • ← → — 快照上一張／下一張

基本使用

點縮圖還原分頁並保留卡片、標題複製連結；編輯按鈕管理 note／tags；展開按鈕查看快照；刪除按鈕移除項目。拖曳可重排；拖到另一張卡片的標題／meta 區可組成 Stack（還原為 Tab Group）。

Tab Group / Stack

Alt+Shift+G 存整組；拖曳 tab 疊合亦可建 Stack。成員面板可預覽、編輯、還原並保留單一或整個 group。

複選

點「選擇」進入複選，勾選多張卡片後可批次還原並保留卡片、合併 tags、或刪除。

備份

精簡 JSON 不含截圖；完整 ZIP 含圖片。還原（覆蓋）取代全部；匯入（附加）只新增。可手動貼 URL 建卡；#GROUP:名稱 包住多行可建群組。

硬碟用量

網址、標題、備註、標籤與設定存在 chrome.storage；截圖、Sticker 附件與自訂背景存在 IndexedDB（通常是最大一塊）。下載資料夾裡的自動備份不算擴充儲存。設定／編輯器顯示的 Sticker 用量只含 Note 附件，不含分頁截圖。

  • 在網址列開 chrome://settings/content/all，搜尋 chrome-extension://（擴充 ID 見 chrome://extensions），即可看到 Storage used。
  • 更精準：在 TabWall 按 ⌥⌘I 開 Console，執行 navigator.storage.estimate()，看 usage（不要看 quota）。

限制

chrome:// 等特殊頁無法截圖或注入。TabWall 的存檔不是 Chrome 書籤列內建的 Save group。
