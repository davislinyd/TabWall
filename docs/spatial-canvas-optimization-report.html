二、卡片互動實作

1. Pointer down在 select 工具下，卡片任何非控制區都開始 node interaction。
→
2. Pointer up短按建立 300ms 預覽排程；超過拖曳閾值則只提交位置。
→
3. Single click沒有第二次點擊時，Tab 開啟既有 lightbox，Group 開啟 mosaic lightbox。
→
4. Double click取消預覽排程，直接呼叫既有 restore 流程。

事件防誤觸

保留 action buttons、連結、輸入控制、搜尋命中區與上下文工具列的控制優先權，不會啟動卡片拖曳或預覽。

Pointer capture 相容

短按預覽同時由 node pointerup 排程，避免 pointer capture 使 click target 變成 viewport 時遺失預覽。

三、Group mosaic 預覽

既有 lightbox 外框

沿用既有 lightbox toolbar、關閉與還原按鈕，不新增另一套 overlay。

放大內容

新增 #lbGroupMosaic，使用最多四個 Group member thumbnail 組成可放大的 mosaic。

還原語意

Group 預覽內的還原按鈕仍呼叫既有 Group confirmation 與 restore 流程。

四、排列模式

棋盤排列 Grid

  • 依目前排序設定產生穩定順序。
  • 欄數使用接近正方形的配置。
  • 依卡片尺寸與固定間距建立 slot，降低卡片重疊。
  • 排列中心對齊目前 viewport；可套用吸附格線。

圓形排列 Circle

  • 所有卡片沿圓環平均分布。
  • 單一卡片時置於 viewport 中心。
  • 半徑依最大卡片尺寸與卡片數計算。
  • 不套用格線吸附，保留圓形幾何。

五、Header 視覺層級修正

body.canvas-mode .header-primary 現在採用：

background: transparent border-bottom: 0 box-shadow: none desktop: 64px mobile: 56px

因此 header-primary 不再覆蓋外層 Canvas header 的背景色，也不會因舊 theme CSS 的 70px 最小高度造成溢出。
