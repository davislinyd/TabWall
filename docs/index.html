本機照片牆

把分頁暫存成可搜尋的空間畫布

TabWall 是 Chromium（Chrome／Edge）擴充功能。它把目前分頁與 Chrome Tab Group 存成帶截圖的卡片，讓你清掉雜亂分頁卻不丟掉脈絡。資料只留在這台電腦的瀏覽器裡。

Park tabs and Tab Groups on a spatial canvas. Search, stack, restore — data stays on your device.

版本 2.33.2 無需帳號 不上傳到 TabWall 伺服器 New Tab 即畫布

五分鐘上手

1

存一頁

打開任意網頁，按 ⌥/Alt+S，或點工具列圖示選「儲存目前分頁」。

2

打開牆

開新分頁就會進入 TabWall；或按 ⌥/Alt+O。

3

找回來

點卡片縮圖還原。不必開牆時，按 ⌥/Alt+/ 直接搜尋並還原。

能做什麼

空間畫布

自由排列、平移縮放、框選、連線、minimap。列表檢視仍保留給大量瀏覽。

Tab Group 與 Stack

整組存進牆；或把卡片拖在一起。還原時重建為真正的 Chrome Tab Group。

搜尋

牆上按 /。任何一般頁按 ⌥/Alt+/。支援 tag／note／group／domain 與 regex。

本機備份

精簡 JSON 或完整 ZIP。可自動寫入 Chrome 下載目錄。不上傳。

安裝

目前以「載入未封裝項目」安裝。請使用乾淨 ZIP（解壓後的資料夾），不要載入整個 Git 倉庫。

  1. 開啟 chrome://extensions（Edge 為 edge://extensions）。
  2. 打開「開發人員模式」。
  3. 選擇「載入未封裝項目」，指定解壓後、內含 manifest.json 的資料夾。
  4. 到 chrome://extensions/shortcuts 確認四個 Chrome 命令是否已綁定。

安裝或更新後，若快捷鍵沒反應，請重新整理該分頁。完整步驟與限制見說明手冊。

隱私

沒有 TabWall 雲端帳號，也不把牆上傳到 TabWall 自有伺服器。網址、備註、標籤與截圖都留在你的瀏覽器本機。
