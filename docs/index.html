把分頁暫存成可搜尋的空間畫布

Park tabs on a searchable spatial canvas

TabWall 是 Chromium（Chrome／Edge）擴充功能。它把目前分頁與 Chrome Tab Group 存成帶截圖的卡片，讓你清掉雜亂分頁卻不丟掉脈絡。資料只留在這台電腦的瀏覽器裡。

TabWall is a Chromium (Chrome / Edge) extension. It parks the current tab or Chrome Tab Group as screenshot cards so you can clear clutter without losing context. Data stays in this browser, on this device.

安裝

Install

目前以「載入未封裝項目」安裝。請使用乾淨 ZIP（解壓後的資料夾），不要載入整個 Git 倉庫。

Install with Load unpacked. Use a clean ZIP (the unzipped folder), not the whole Git repository.

  1. 開啟 chrome://extensions（Edge 為 edge://extensions）。
  2. Open chrome://extensions (or edge://extensions on Edge).
  3. 打開右上角「開發人員模式」。
  4. Turn on Developer mode.
  5. 選擇「載入未封裝項目」，指定解壓後的 TabWall 資料夾（內含 manifest.json）。
  6. Choose Load unpacked and select the unzipped TabWall folder (it must contain manifest.json).
  7. 到 chrome://extensions/shortcuts 確認四個 Chrome 命令是否已綁定。衝突時請改成你習慣的組合。
  8. Check chrome://extensions/shortcuts and bind the four Chrome commands if they are empty or conflicting.

安裝、重新載入或更新後，若網頁上的浮層或 ⌥/Alt+/ 沒反應，請重新整理該分頁。舊頁面可能仍掛著上一版注入腳本。

After install, reload, or update, refresh the tab if the overlay or ⌥/Alt+/ does nothing. The page may still be running an older injected script.

五分鐘上手

Five-minute start

1

存一頁

Park a page

打開任意網頁，按 ⌥/Alt+S，或點工具列圖示選「儲存目前分頁」。

On any page, press ⌥/Alt+S, or use the toolbar icon and choose park current tab.

2

打開牆

Open the wall

開新分頁就會進入 TabWall；或按 ⌥/Alt+O，或在 popup 按「打開 TabWall 面板」。

A new tab opens TabWall. Or press ⌥/Alt+O, or click Open TabWall in the popup.

3

找回來

Restore

點卡片縮圖還原分頁。群組會先問一次。不必開牆時，按 ⌥/Alt+/ 直接搜尋並還原。

Click a thumbnail to restore. Groups ask first. Or press ⌥/Alt+/ to search and restore without opening the wall.

畫布上的「說明」按鈕可隨時打開精簡版提示。本手冊是完整版。

The in-app Help button shows a short version. This page is the full guide.

三種入口

Three ways in

工具列 popup

Toolbar popup

點 TabWall 圖示後可分別：

Click the TabWall icon to:

  • 儲存目前分頁（關閉／不關閉）
  • Park the current tab (close or keep)
  • 儲存目前 Tab Group（關閉／不關閉）
  • Park the current Tab Group (close or keep)
  • 打開 TabWall 面板
  • Open the TabWall panel

目前分頁不在 Tab Group 時，群組按鈕會停用。

Group actions are disabled when the current tab is not in a Tab Group.

New Tab／獨立頁

New Tab / standalone

新分頁直接顯示空間畫布。受限頁（例如 chrome://）無法注入浮層時，會改開或聚焦獨立 TabWall 分頁。

New Tab opens the canvas. Restricted pages such as chrome:// cannot host the overlay, so TabWall opens or focuses a standalone tab instead.

網頁浮層

Page overlay

一般網站可用 Chrome 快捷鍵開關畫布、儲存分頁或群組。浮層佔視窗 98%，其餘 2% 是原頁模糊框。圖示右下角若出現綠色勾，代表這個網址已在牆裡（獨立卡片或群組成員）。

On normal websites, Chrome shortcuts toggle the canvas or park a tab or group. The overlay fills 98% of the viewport; the remaining 2% is a blurred frame of the host page. A green check on the icon means this URL is already on the wall (as a card or a group member).

儲存前編輯與自動規則

Edit before save and rules

儲存前編輯

Edit before saving

預設開啟。儲存單一分頁（快捷鍵、popup 的分頁按鈕、Overlay 快速儲存）時，會先跳出面板讓你改 note／tag，確認後才寫入；取消則分頁維持原狀。

On by default. Parking a single tab (shortcuts, popup tab buttons, overlay quick-save) opens a panel for note/tags first. Confirm writes it; cancel leaves the tab untouched.

Group 儲存不受這項影響。可在設定關閉「儲存前先編輯 Note／Tag」。

Group saves skip this panel. Turn it off in Settings → Edit before saving.

自動 Note／Tag 規則

Automatic note / tag rules

設定 → 儲存規則。依 hostname／FQDN 或 page title，用 match、contains、starts with、ends with、regex、not 判斷；每條規則可選 AND／OR。

Settings → Save rules. Match hostname / FQDN or page title with match, contains, starts with, ends with, regex, or not. Each rule can use AND or OR.

  • 命中後：note 逐行附加並去重，tag 合併並去重。
  • On a hit: note lines append without duplicates; tags merge without duplicates.
  • 存 Group 時會逐一判斷成員。
  • Group saves evaluate each member separately.
  • 儲存前編輯面板會預填這些規則的結果，你仍可改。
  • The edit-before-save panel is prefilled from matching rules; you can still change it.

同一瀏覽器工作階段裡，還原過的分頁或群組若再次儲存，會沿用原本的備註與標籤。

If you restore a tab or group and park it again in the same browser session, the original notes and tags come back.

空間畫布

Spatial canvas

預設檢視是可平移、縮放的無限畫布。卡片預覽固定 16:10。100% 縮放時卡片視覺大約放大 10%，儲存的座標格式不變。

The default view is an infinite canvas you can pan and zoom. Card previews are 16:10. At 100% zoom cards look about 10% larger; stored positions stay compatible.

During search, hits temporarily snap to a grid. Drags and arrange in that state are preview-only: they do not save positions or create Stacks. Connections still work and persist. Clearing search restores the real layout.

卡片與還原

Cards and restore

  • 點縮圖：還原分頁；群組會先確認。
  • Click the thumbnail to restore. Groups ask first.
  • 點標題或中繼資料：複製已存網址（群組則複製成員網址）。
  • Click the title or metadata to copy the saved URL (or member URLs for a group).
  • 點編輯：改顯示標題、note／tags 與上鎖設定。Note 可點標題進入。
  • Click Edit for display titles, notes/tags, and lock settings. Notes also open from the title.
  • 點展開：看全尺寸快照。沒有全圖時顯示縮圖。快照裡用 ←／→ 切上一張／下一張。
  • Click Expand for the full snapshot (thumbnail if none). Use ← / → for previous / next.
  • 點固定：只作用於頂層項目。工具列「已固定」是篩選，不改手動順序，也不寫進備份的篩選狀態。
  • Click Pin on top-level items. The Pinned filter does not change manual order or backup state.
  • 點刪除：從牆移除。
  • Click Delete to remove it from the wall.

自訂顯示標題與原始名稱

Display titles and subtitles

在編輯盒中設定「顯示標題」後，卡片主標題會改用自訂名稱，下方以小字保留分頁或群組的原始名稱。搜尋與 Option+/ 快速搜尋會同時比對自訂名稱與原始名稱。

Set a Display title in the edit box to replace the main title while keeping the original page or group title in a small subtitle line. Plain search and Option+/ search match both display and original titles.

卡片上鎖與隱私（可選密碼）

Card lock and privacy

分頁卡、Group、圖片卡、Sticker Note 及 Group 成員皆可在編輯盒勾選「上鎖」。上鎖後縮圖與快照會被鎖頭遮罩隱藏，避免他人直接看到畫面；還原分頁或編輯備註不需解鎖。解鎖狀態僅保留在本次打開分頁的記憶體中（關閉後自動重新上鎖）。可選填密碼（以 SHA-256 加鹽雜湊驗證），不設密碼時點擊鎖頭即可直接解鎖。

Tab cards, groups, image cards, notes, and group members can be locked from the edit box. Locking hides thumbnails and full snapshots with a lock overlay so passersby cannot see page contents. Restoring tabs and editing notes still work without unlocking. Unlocking lasts only for the current tab session (re-locks upon closing). An optional password uses salted SHA-256 hash; without a password, clicking the lock unlocks immediately.

群組卡片

Group cards

展開後是可操作的成員格，不是死馬賽克。可預覽、編輯、還原單一成員或整個 Group。還原 Group 時可選目前視窗或新視窗；note 成員不會變成瀏覽器分頁。群組卡有色條與淡色，方便和一般分頁區分。

Expanding a group opens a live member grid, not a dead mosaic. Preview, edit, or restore one member or the whole group. Restore can target the current window or a new one. Note members never become browser tabs. Group cards have a color bar and tint so they stand apart from tab cards.

圖片卡

Image cards

用「新增卡片」上傳、貼上或拖放本機圖片。支援 JPEG、PNG、WEBP、GIF、SVG、HEIC。會壓縮成縮圖與快照，以 contain 填滿節點。這不是分頁，點縮圖不會還原瀏覽器分頁。

Use Add card to upload, paste, or drop a local image. JPEG, PNG, WEBP, GIF, SVG, and HEIC are accepted. Files are compressed to a thumbnail and snapshot, and fill the node with contain. This is not a tab — clicking it does not restore a browser tab.

Sticker Note

便條只活在畫布上，用來寫脈絡、貼圖、跟分頁放在一起。可以加入 Stack，永遠不會還原成瀏覽器分頁。

Notes live only on the canvas — context, images, next to tabs. They can join Stacks and are never restored as browser tabs.

  • 標題、標籤、安全 Markdown 預覽。
  • Title, tags, and a safe Markdown preview.
  • 最多 12 張本機圖片。新圖會轉成 WebP（不行就 PNG）；長邊 ≤ 4096px、總像素 ≤ 16MP；原始檔與輸出檔各 ≤ 24 MiB。
  • Up to 12 local images. New files become WebP (PNG fallback); long edge ≤ 4096px, 16MP max, 24 MiB per source and output file.
  • GIF／SVG 會變成靜態圖。
  • GIF and SVG become static images.
  • 單一 note 附件合計 ≤ 96 MiB；整個擴充功能附件 ≤ 512 MiB。舊附件不會自動遷移，限制套用在新上傳與匯入。
  • 96 MiB attachments per note, 512 MiB across the extension. Existing attachments are not migrated; limits apply to new uploads and imports.

Stack 與 Tab Group

Stacks and Tab Groups

兩種「一組東西」不要混為一談：

These are not the same thing:

Chrome Tab Group

瀏覽器原生群組。用 ⌥+Shift+G 或 popup 整組存進牆。還原時重建為真正的 Tab Group。

A native browser group. Park it with ⌥+Shift+G or the popup. Restore recreates a real Tab Group.

Canvas Stack

在牆上把兩張以上卡片疊在一起：多選後合併，或把一張拖到另一張標題區。分頁成員還原成 Tab Group；note 留在畫布。誤疊可用 ⌘+Z／Ctrl+Z 復原。

Stack two or more cards on the wall: multi-select and merge, or drop one onto another’s title. Tab members restore as a Tab Group; notes stay on the canvas. Undo an accidental stack with ⌘+Z / Ctrl+Z.

TabWall 的存檔不是 Chrome 書籤列內建的 Save group。兩邊資料不相通。

TabWall is not Chrome’s built-in bookmark Save group. The two stores do not sync.

牆上搜尋

Wall search

在牆上按 / 聚焦搜尋框。不分大小寫，輸入有短暫延遲；縮圖接近可視範圍才載入。

Press / on the wall to focus search. Matching is case-insensitive and debounced. Thumbnails load near the visible area.

Tag 模式

Tag mode

會出現即時建議。可多選 tag。用 &&／|| 組合；點建議旁的 || 或按 Alt+Enter 以「或」加入。此模式下空白不是 AND 分隔符，以便 tag 名稱本身含空白。

A type-ahead list appears. Pick multiple tags. Combine with && / ||; click || on a suggestion or press Alt+Enter to insert OR. In tag mode, spaces are not AND, so tag names that contain spaces still work.

群組命中時，卡片會列出符合的成員分頁與 note。若命中卡片有直接畫布連線，會多顯示一層關聯卡片（較淡；游標移上去或聚焦會恢復）。

When a group matches, the card lists matching member tabs and notes. A direct canvas connection also shows one related card, faded until hover or focus.

Option+/ 快速搜尋

Option+/ quick search

在任何一般網頁（不必打開 TabWall）按 ⌥/Alt+/ 開啟輕量面板。

On any normal page (the wall does not need to be open), press ⌥/Alt+/.

  • 左欄結果（最多 12 筆），右欄預覽截圖、note、tags、成員。
  • Results on the left (up to 12). Snapshot, note, tags, and members on the right.
  • 方向鍵移動；Enter 或雙擊還原分頁／群組。Note 不能還原成分頁。
  • Arrow keys move. Enter or double-click restores a tab or group. Notes cannot restore a tab.
  • 欄位切換與牆上相同：tag／group／note／domain 再按 Tab；all+Tab 重設。
  • Same field scopes as the wall: tag / group / note / domain then Tab; all+Tab resets.
  • Esc 關閉。closes it.

這不是 Chrome command，無法在 chrome://extensions/shortcuts 改鍵。特殊頁無法注入時請改開 TabWall 本體搜尋。

This is not a Chrome command, so it cannot be rebound in chrome://extensions/shortcuts. On pages that cannot be injected, search inside TabWall instead.

列表、標籤與批次

List, tags, and batch

列表檢視

List view

標題列可在畫布與列表之間切換。列表是較密、較利於鍵盤與大量瀏覽的 fallback；畫布座標與列表排序互不覆蓋。

The header switches canvas and list. List is the dense, keyboard-friendly fallback. Canvas positions and list order do not overwrite each other.

列表可用「欄數」滑桿（4–10）。窄視窗仍維持桌面版面，必要時水平捲動，沒有手機重排。

List columns are 4–10. Narrow windows keep the desktop layout and scroll horizontally. There is no mobile reflow.

Tags

標題列「Tags」開啟管理抽屜：搜尋、新增、重新命名、刪除。刪除 tag 會從所有已存項目移除該標籤。

Header → Tags opens the manager: search, add, rename, delete. Deleting a tag removes it from every parked item.

複選與批次

Multi-select and batch

按「選擇」進入複選。勾選後可批次還原、附加 note／tags（不覆蓋既有內容）、刪除，或只匯出選取的卡片（精簡 JSON／完整 ZIP）。

Turn on Select, pick cards, then batch restore, append notes / tags (without overwriting existing text), delete, or export only the selection (lite JSON or full ZIP).

Shift／Control 可在畫布上加選。

Hold Shift / Control to add to the canvas selection.

設定

自訂背景

Custom background

設定 → 顯示 → 背景。上傳一張靜態圖片；與 Sticker Note 附件相同會壓縮並正規化（WebP，必要時 PNG）。不支援影片。

Settings → Display → Background. Upload one static image. It is compressed and normalized like a Sticker Note attachment (WebP, PNG fallback). Video is not supported.

  • 符合方式：置中、符合寬度、符合高度、原始大小。
  • Fit: center, fit to width, fit to height, or original size.
  • 模糊：0–32px，預設 16。濃度：15–70%，預設 40。另有主題洗色，避免蓋過卡片。
  • Blur: 0–32px, default 16. Strength: 15–70%, default 40. A theme wash keeps cards readable.
  • 圖片存在本機 IndexedDB；符合方式、模糊、濃度存在設定。
  • The image lives in local IndexedDB; fit, blur, and strength live in settings.
  • 按「移除」刪掉背景圖與設定。
  • Remove deletes the image and the wallpaper settings.

備份與還原

Backup and restore

精簡 JSON

Lite JSON

保留網址、標題、note、tags、附件 metadata，以及背景的符合／模糊／濃度設定。不含截圖、附件或背景圖檔。檔案小，適合日常與自動備份。

Keeps URLs, titles, notes, tags, attachment metadata, and wallpaper fit / blur / strength. No screenshot, attachment, or wallpaper image binaries. Small enough for daily and automatic backups.

完整 ZIP

Full ZIP

另外帶本機圖片與自訂背景圖。預估超過 256 MiB 會拒絕，請改精簡或分批（多選匯出）。還原預覽可看圖；精簡預覽看文字與成員。

Includes local images and the custom wallpaper. Export is refused above about 256 MiB — use lite or export a selection. Full restore previews images; lite previews text and members.

  • 還原（覆蓋）：取代牆上全部資料（含自訂背景），會再確認一次。
  • Restore (replace) overwrites everything on the wall, including the custom wallpaper, after a confirm.
  • 匯入（附加）：只新增卡片，不刪現有項目，也不覆寫目前背景。選檔後可挑要寫入哪些分頁與群組。
  • Import (append) only adds cards. It does not delete existing items and does not overwrite the current wallpaper. After picking a file, choose which tabs and groups to write.
  • 檔名使用本機時間與 UTC 時差，例如 2026-08-04T13-00-00+0800。
  • Filenames use local time and the UTC offset, for example 2026-08-04T13-00-00+0800.

自動備份

Automatic backup

寫入 Chrome「下載位置」底下你指定的子資料夾（不一定是 Downloads，請看 chrome://settings/downloads）。可依排程、或資料變更後備份；保留 1–99 份。開新分頁只在間隔已到期時才補跑，不會每次開牆就下載。TabWall 會辨識自己寫出的備份並刪舊檔。不上傳。

Writes into a subfolder of Chrome’s download location (not always Downloads — see chrome://settings/downloads). Run on a schedule and/or after data changes. Keep 1–99 copies. Opening a new tab only catch-up backups if the interval is already overdue. TabWall recognizes its own files and deletes older ones. Nothing is uploaded.

硬碟用量

Disk usage

資料只留在這台電腦的瀏覽器。應用內說明也有精簡版。

Data stays in this browser, on this device. In-app Help has a short version of this section.

  • 網址、標題、備註、標籤與設定存在 chrome.storage.local，通常只有數 MB。
  • URLs, titles, notes, tags, and settings live in chrome.storage.local — usually a few megabytes.
  • 縮圖、完整快照、圖片卡、Sticker 附件與自訂背景存在 IndexedDB（通常是最大一塊）。

  • Automatic backups in the download folder are ordinary files. They are not extension storage, and uninstalling does not delete them.
  • 設定／編輯器顯示的 Sticker 用量只含 Note 附件配額，不含分頁截圖或 wallpaper。
  • The sticker usage meter counts note-attachment quota only, not tab screenshots or wallpaper.

怎麼查看目前用量

How to see current usage

  1. 開 chrome://settings/content/all，搜尋 chrome-extension://（擴充 ID 在 chrome://extensions），看 Storage used。
  2. Open chrome://settings/content/all, search for chrome-extension:// (the ID is on chrome://extensions), and read Storage used.
  3. 更精準：在 TabWall 按 ⌥+⌘+I 開 Console，執行 navigator.storage.estimate()，看 usage（不要看 quota；有 unlimitedStorage 時 quota 接近整顆碟）。例如 33740107 bytes ≈ 32.2 MiB。
  4. More precise: on TabWall, open the Console with ⌥+⌘+I and run navigator.storage.estimate(). Read usage, not quota (with unlimitedStorage, quota is nearly the whole disk). Example: 33740107 bytes ≈ 32.2 MiB.

限制與常見問題

Limits and FAQ

做不到的事

What it cannot do

  • chrome://、edge://、Chrome Web Store 等受限頁無法截圖或注入浮層。
  • chrome://, edge://, and the Chrome Web Store cannot be captured or injected.
  • 不是 Chrome 書籤、不是同步帳號、不能當跨裝置雲端牆。
  • It is not Chrome bookmarks, not a sync account, and not a cross-device cloud wall.
  • 沒有手機版重排或觸控工具列。
  • There is no mobile reflow or touch toolbar.
  • 背景只接受靜態圖片，不支援影片或動態桌布。
  • Backgrounds are static images only. Video and live wallpapers are not supported.
  • Sticker Note 不能還原成分頁；file: 一類 stored-only 項目也不可直接還原。
  • Sticker Notes cannot restore as tabs. Stored-only items such as file: URLs also cannot restore directly.

快捷鍵沒反應

Shortcuts do nothing

  1. 到 chrome://extensions/shortcuts 看四個命令是否「未綁定」或跟別的擴充功能衝突。
  2. Check chrome://extensions/shortcuts for unbound or conflicting commands.
  3. 重新整理目前分頁（更新後舊注入會失效）。
  4. Refresh the tab (old injections die after an update).
  5. 牆上內建鍵（/、搜尋模式、Esc、⌘+Z、快照方向鍵）不能在 Chrome 設定改。
  6. In-wall keys (/, search modes, Esc, ⌘+Z, snapshot arrows) cannot be changed in Chrome settings.

畫布很空或卡片跑很遠

The canvas looks empty or cards are far away

新卡片會靠近既有群配置到下一個不重疊格。可用「畫布整理」重新棋盤／對齊，或雙擊中鍵重設視角。

New cards land near the existing cluster in the next free cell. Use Arrange canvas, or double-click the middle mouse button to reset the view.
