把分頁暫存成可搜尋的空間畫布

TabWall 是 Chromium（Chrome／Edge）擴充功能。它把目前分頁與 Chrome Tab Group 存成帶截圖的卡片，讓你清掉雜亂分頁卻不丟掉脈絡。資料只留在這台電腦的瀏覽器裡。

版本 2.33.2 無需帳號 不上傳到 TabWall 伺服器 New Tab 即畫布

手冊中沒有符合的段落。試試「備份」「搜尋」或「快捷鍵」。

安裝

目前以「載入未封裝項目」安裝。請使用乾淨 ZIP（解壓後的資料夾），不要載入整個 Git 倉庫。

  1. 開啟 chrome://extensions（Edge 為 edge://extensions）。
  2. 打開右上角「開發人員模式」。
  3. 選擇「載入未封裝項目」，指定解壓後的 TabWall 資料夾（內含 manifest.json）。
  4. 到 chrome://extensions/shortcuts 確認四個 Chrome 命令是否已綁定。衝突時請改成你習慣的組合。

安裝、重新載入或更新後，若網頁上的浮層或 ⌥/Alt+/ 沒反應，請重新整理該分頁。舊頁面可能仍掛著上一版注入腳本。

五分鐘上手

1

存一頁

打開任意網頁，按 ⌥/Alt+S，或點工具列圖示選「儲存目前分頁」。

2

打開牆

開新分頁就會進入 TabWall；或按 ⌥/Alt+O，或在 popup 按「打開 TabWall 面板」。

3

找回來

點卡片縮圖還原分頁。群組會先問一次。不必開牆時，按 ⌥/Alt+/ 直接搜尋並還原。

畫布上的「說明」按鈕可隨時打開精簡版提示。本手冊是完整版。

三種入口

工具列 popup

點 TabWall 圖示後可分別：

  • 儲存目前分頁（關閉／不關閉）
  • 儲存目前 Tab Group（關閉／不關閉）
  • 打開 TabWall 面板

目前分頁不在 Tab Group 時，群組按鈕會停用。

New Tab／獨立頁

新分頁直接顯示空間畫布。受限頁（例如 chrome://）無法注入浮層時，會改開或聚焦獨立 TabWall 分頁。

網頁浮層

一般網站可用 Chrome 快捷鍵開關畫布、儲存分頁或群組。圖示右下角若出現綠色勾，代表這個網址已在牆裡（獨立卡片或群組成員）。

儲存前編輯與自動規則

儲存前編輯

預設開啟。儲存單一分頁（快捷鍵、popup 的分頁按鈕、Overlay 快速儲存）時，會先跳出面板讓你改 note／tag，確認後才寫入；取消則分頁維持原狀。

Group 儲存不受這項影響。可在設定關閉「儲存前先編輯 Note／Tag」。

自動 Note／Tag 規則

設定 → 儲存規則。依 hostname／FQDN 或 page title，用 match、contains、starts with、ends with、regex、not 判斷；每條規則可選 AND／OR。

  • 命中後：note 逐行附加並去重，tag 合併並去重。
  • 存 Group 時會逐一判斷成員。
  • 儲存前編輯面板會預填這些規則的結果，你仍可改。

同一瀏覽器工作階段裡，還原過的分頁或群組若再次儲存，會沿用原本的備註與標籤。

空間畫布

預設檢視是可平移、縮放的無限畫布。卡片預覽固定 16:10。100% 縮放時卡片視覺大約放大 10%，儲存的座標格式不變。

搜尋進行中，命中卡片會暫時排成棋盤。這段期間的拖曳與排列只是預覽，不會寫回正式座標，也不會因拖放建立 Stack。清空搜尋後恢復原布局。

卡片與還原

  • 點縮圖：還原分頁；群組會先確認。
  • 點標題或中繼資料：複製已存網址（群組則複製成員網址）。
  • 點編輯：改 note／tags。Note 可點標題進入。
  • 點展開：看全尺寸快照。沒有全圖時顯示縮圖。快照裡用 ←／→ 切上一張／下一張。
  • 點固定：只作用於頂層項目。工具列「已固定」是篩選，不改手動順序，也不寫進備份的篩選狀態。
  • 點刪除：從牆移除。

群組卡片

展開後是可操作的成員格，不是死馬賽克。可預覽、編輯、還原單一成員或整個 Group。還原 Group 時可選目前視窗或新視窗；note 成員不會變成瀏覽器分頁。

Sticker Note

便條只活在畫布上，用來寫脈絡、貼圖、跟分頁放在一起。可以加入 Stack，永遠不會還原成瀏覽器分頁。

  • 標題、標籤、安全 Markdown 預覽。
  • 最多 12 張本機圖片。新圖會轉成 WebP（不行就 PNG）；長邊 ≤ 4096px、總像素 ≤ 16MP；原始檔與輸出檔各 ≤ 24 MiB。
  • GIF／SVG 會變成靜態圖。
  • 單一 note 附件合計 ≤ 96 MiB；整個擴充功能附件 ≤ 512 MiB。舊附件不會自動遷移，限制套用在新上傳與匯入。

Stack 與 Tab Group

兩種「一組東西」不要混為一談：

Chrome Tab Group

瀏覽器原生群組。用 ⌥+Shift+G 或 popup 整組存進牆。還原時重建為真正的 Tab Group。

Canvas Stack

在牆上把兩張以上卡片疊在一起：多選後合併，或把一張拖到另一張標題區。分頁成員還原成 Tab Group；note 留在畫布。

TabWall 的存檔不是 Chrome 書籤列內建的 Save group。兩邊資料不相通。

牆上搜尋

在牆上按 / 聚焦搜尋框。不分大小寫，輸入有短暫延遲；縮圖接近可視範圍才載入。

輸入意義
grafana zabbix 或 &&且（AND）
grafana||zabbix或（OR）
t／tag 再按 Tab只搜標籤
n／note 再按 Tab只搜備註
g／group 再按 Tab只搜群組名稱／成員
d／domain 再按 Tab只搜 hostname（獨立分頁與群組成員；不含 Sticker Note）
re／regex 再按 Tab，或工具列 .*正規表示式；支援 /pattern/flags
all 再按 Tab回到全欄位
空白搜尋時 Backspace／Delete／Esc離開目前欄位或 regex 模式

Tag 模式

會出現即時建議。可多選 tag。用 &&／|| 組合；點建議旁的 || 或按 Alt+Enter 以「或」加入。此模式下空白不是 AND 分隔符，以便 tag 名稱本身含空白。

群組命中時，卡片會列出符合的成員分頁與 note。若命中卡片有直接畫布連線，會多顯示一層關聯卡片（較淡；游標移上去或聚焦會恢復）。

Option+/ 快速搜尋

在任何一般網頁（不必打開 TabWall）按 ⌥/Alt+/ 開啟輕量面板。

  • 左欄結果（最多 12 筆），右欄預覽截圖、note、tags、成員。
  • 方向鍵移動；Enter 或雙擊還原分頁／群組。Note 不能還原成分頁。
  • 欄位切換與牆上相同：tag／group／note／domain 再按 Tab；all+Tab 重設。
  • Esc 關閉。

這不是 Chrome command，無法在 chrome://extensions/shortcuts 改鍵。特殊頁無法注入時請改開 TabWall 本體搜尋。

列表、標籤與批次

列表檢視

標題列可在畫布與列表之間切換。列表是較密、較利於鍵盤與大量瀏覽的 fallback；畫布座標與列表排序互不覆蓋。

列表可用「欄數」滑桿（4–10）。窄視窗仍維持桌面版面，必要時水平捲動，沒有手機重排。

Tags

標題列「Tags」開啟管理抽屜：搜尋、新增、重新命名、刪除。刪除 tag 會從所有已存項目移除該標籤。

複選與批次

按「選擇」進入複選。勾選後可批次還原、合併 tags、編輯 note、刪除，或只匯出選取的卡片（精簡 JSON／完整 ZIP）。

Shift／Control 可在畫布上加選。

設定

牆上按「設定」，或 Mac ⌥+⌘+S、Windows Alt+Win+S。變更會自動儲存。

分頁內容
一般語言、儲存分頁／Group 後是否關閉、儲存前編輯、Group 截圖範圍、還原 Group 到目前視窗或新視窗。
儲存規則自動 Note／Tag 條件與附加內容。
顯示主題（淺／深；新安裝預設深色工作台）、視覺效果（安靜／標準／電影感；系統「減少動態效果」會強制安靜）、預設欄數與檢視、開啟時是否聚焦搜尋。
整理與畫布／列表整理相關的偏好。
備份手動匯出／還原／附加，以及自動備份。
快捷鍵只讀顯示 Chrome 綁定；可開啟 Chrome 設定頁。不能在 TabWall 裡錄製熱鍵。
診斷匯出、匯入、自動備份事件。可複製或清除。

標題列的 Light／Dark 可快速切主題。背景是靜態主題，不支援影片背景或自行匯入影片。

備份與還原

精簡 JSON

保留網址、標題、note、tags、附件 metadata。不含截圖與圖片二進位。檔案小，適合日常與自動備份。

完整 ZIP

另外帶本機圖片。預估超過 256 MiB 會拒絕，請改精簡或分批（多選匯出）。還原預覽可看圖；精簡預覽看文字與成員。

  • 還原（覆蓋）：取代牆上全部資料，會再確認一次。
  • 匯入（附加）：只新增，不刪現有卡片。選檔後可挑要寫入哪些分頁與群組。
  • 檔名使用本機時間與 UTC 時差，例如 2026-08-04T13-00-00+0800。

自動備份

寫入 Chrome「下載位置」底下你指定的子資料夾（不一定是 Downloads，請看 chrome://settings/downloads）。可依排程、或資料變更後備份；保留 1–99 份。TabWall 會辨識自己寫出的備份並刪舊檔。不上傳。

去重複

儲存時若牆上已有完全相同的 URL，會詢問：保留兩者、取代舊項、或取消。

工具列「更多工具」→「掃描重複」可掃整牆，選擇只留最新、只留最舊、全部保留，再套用刪除。

隱私與資料

  • 沒有 TabWall 雲端帳號，也不把牆上傳到 TabWall 自有伺服器。
  • 網址、標題、note、tags、排序存在 chrome.storage.local。
  • 縮圖與快照存在本機 IndexedDB。
  • 只在你操作（含 Chrome 快捷鍵）時讀取目前分頁／群組來截圖與儲存。
  • 解除安裝會依瀏覽器機制清除擴充功能本機資料。已下載的備份檔仍在下載目錄，需自行刪。

完整條款見 隱私權政策。

限制與常見問題

做不到的事

  • chrome://、edge://、Chrome Web Store 等受限頁無法截圖或注入浮層。
  • 不是 Chrome 書籤、不是同步帳號、不能當跨裝置雲端牆。
  • 沒有手機版重排或觸控工具列。
  • Sticker Note 不能還原成分頁；file: 一類 stored-only 項目也不可直接還原。

快捷鍵沒反應

  1. 到 chrome://extensions/shortcuts 看四個命令是否「未綁定」或跟別的擴充功能衝突。
  2. 重新整理目前分頁（更新後舊注入會失效）。
  3. 牆上內建鍵（/、搜尋模式、Esc、快照方向鍵）不能在 Chrome 設定改。

畫布很空或卡片跑很遠

新卡片會靠近既有群配置到下一個不重疊格。可用「畫布整理」重新棋盤／對齊，或雙擊中鍵重設視角。
